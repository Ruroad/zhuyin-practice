# 潾潾學注音 🐮

給準備上小學的小朋友練習注音符號的網頁 App，以 iPad 為主要裝置。由潾潾小牛陪小朋友一起練習。

## 功能（第一個原型）

- **第一關**：ㄅ ㄆ ㄇ ㄈ ＋ ㄚ ㄛ ㄜ ㄝ
- **四種題型**
  - 👀 認識：點符號，聽發音、看圖
  - 👂 聽一聽：聽聲音，選出對的符號
  - 🎵 四聲：聽一個音，選出第幾聲
  - 🧩 拼一拼：把聲母和韻母拖進格子，拼出聽到的音（兩拼）
- **答錯處理**：先鼓勵、重播再試一次；第二次還錯就提示答案。常錯的會比較常出現（間隔複習）
- **獎勵**：每完成一次練習得到星星和一張貼紙，可以在貼紙本收藏
- **多位小朋友**：用頭像切換
- **家長專區**（需回答算術題）：每日時間上限、各符號答對率、最常錯的題目、匯出／匯入進度
- **發音錄音**（在家長專區）：用 iPad 直接錄音，或上傳錄好的檔案（例如語音備忘錄），用家長的聲音取代語音合成
- **離線使用**：在 iPad Safari 按「分享 → 加入主畫面」，就能像 App 一樣使用

進度和錄音只存在這台裝置的瀏覽器裡，沒有帳號、不會上傳。匯出的備份檔會包含錄音。

## 聲音

播放順序：

1. 家長在「家長專區 → 發音錄音」錄的聲音
2. `audio/` 資料夾裡的音檔（所有裝置共用，見 [`audio/README.md`](audio/README.md)）
3. iPad 內建的台灣中文語音合成

## 本機執行

不需要安裝任何東西，在專案資料夾執行：

```sh
python3 -m http.server 8000
```

然後打開 http://localhost:8000。

## 新增關卡

在 `js/data.js` 的 `LEVELS` 加一筆，並在 `SYMBOLS`、`SYLLABLES` 補上內容。改了檔案後，記得把 `sw.js` 裡的 `VERSION` 加一。
