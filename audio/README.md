# 音檔

這個資料夾放注音的發音音檔（mp3）。沒有音檔的項目，會改用平板內建的語音合成來唸。
家長在「家長專區 → 發音錄音」錄的聲音，會優先於這裡的音檔。

## 目前的音檔從哪裡來

目前的 23 個音檔，是用開源離線語音模型
[sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) 的 `matcha-icefall-zh-baker`
（標準普通話女聲）加上 `vocos-22khz-univ` 聲碼器生成的。每個音都直接指定拼音和聲調，
再用兩個語音辨識模型（Paraformer、SenseVoice）交叉檢查：兩個都聽對、而且沒有多餘的字才採用。

注意：

- 這是大陸普通話的聲音，不是台灣口音。這些簡單音節差異不大，但仍建議家長試聽。
- 據我所知，這個模型的訓練資料（標貝中文標準女聲音庫）只授權非商業使用；
  如果將來要做成商業產品，請換成自己錄的音檔。
- 以下音沒有通過檢查，所以沒有音檔，建議家長自己錄：
  ㄈ、ㄝ、ㄅㄚˊ、ㄅㄚˇ、ㄆㄚ、ㄈㄚˊ、ㄅㄛˇ、ㄆㄛˇ、ㄇㄛˇ、ㄇㄛˋ、ㄈㄛˊ

## 檔名規則

| 種類 | 檔名 | 例子 |
|---|---|---|
| 單一符號 | `sym-<代號>.mp3` | `sym-b.mp3`（ㄅ） |
| 兩拼音節 | `syl-<聲母代號><韻母代號><聲調>.mp3` | `syl-ma3.mp3`（ㄇㄚˇ） |

代號：ㄅ=b、ㄆ=p、ㄇ=m、ㄈ=f、ㄚ=a、ㄛ=o、ㄜ=e、ㄝ=eh。聲調 1–4。

## 放好檔案之後

1. 把檔名（不含 `.mp3`）加到 `js/data.js` 的 `AUDIO_FILES` 裡，例如 `'sym-b'`。
2. 把檔案路徑加到 `sw.js` 的 `FILES`（離線也能用），並把 `VERSION` 加一。
